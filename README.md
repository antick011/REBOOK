# REBOOK

**REBOOK** is a Django-based platform for buying and reselling used books. It allows users to list their pre-owned books for sale, browse available listings, and make purchases. The platform fosters sustainability by promoting the reuse of books.

> **Note:** This project is **for educational purposes only**.  
> **Cloning, forking, or copying this code is strictly prohibited**. The code is not open source and cannot be reused without explicit permission.

## Features

- Buy and sell used books
- User authentication to manage listings and orders
- Browse and search through book listings
- Simple and intuitive user interface

## Technologies Used

- **Framework**: Django
- **Language**: Python
- **Database**: SQLite (default)
